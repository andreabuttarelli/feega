# feega mobile

Capacitor app for iPhone, iPad and (later) Android: native screens around a web canvas
(ADR 0018). Desktop stays on Tauri (`apps/native`). Not part of the npm workspace or CI.

```
ios/App            Xcode project generated by Capacitor (AppDelegate, SceneDelegate → SwiftUI)
ios/FeegaKit       Swift package: FeegaCore (auth, API client, contract, cookies, cache; tested
                   with `swift test`) and FeegaUI (SwiftUI screens, WebView screen, perf probe)
contract/          api.schema.json, generated from src/lib/api/mobile-contract.ts
android/           Capacitor scaffold, no native screens yet
```

## Build for the simulator

```bash
cd apps/mobile
npm install
bash scripts/vendor-capacitor.sh   # Capacitor xcframeworks as a local package (SwiftPM's own
                                   # binary download hangs here; Xcode uses this as an override)
npm run config        # FeegaConfig.plist from ../../.env (Supabase URL + anon key, public)
npm run wire          # once: links FeegaKit and the plist into the Xcode project
npm run ios:sim       # unsigned simulator build in build/ios
(cd ios/FeegaKit && swift test)
```

`npm run config` points the app at `https://oh.feega.app`. To use a local server for the API
(e.g. endpoints not deployed yet): `FEEGA_API=http://localhost:5197 npm run config`; the canvas
WebView keeps loading `FEEGA_WEB` (default production).

`npx cap sync ios` rewrites `ios/App/CapApp-SPM/Package.swift`; run `npm run wire` again after it
only if the FeegaKit reference disappeared.

## Install the debug build on your own iPhone (free Apple ID, no paid account)

1. Xcode → Settings → Accounts → `+` → Apple ID. A "Personal Team" appears.
2. `npm run config` (production) and open `ios/App/App.xcodeproj`.
3. Target **App** → Signing & Capabilities: tick "Automatically manage signing", Team = your
   Personal Team, and change Bundle Identifier to something unique, e.g. `app.feega.mobile.<you>`
   (a free team cannot use `app.feega.mobile`).
4. Plug in the iPhone, unlock it, trust the Mac. On iOS 16+ enable Settings → Privacy & Security →
   Developer Mode and restart.
5. Pick the iPhone as run destination, press Run (⌘R).
6. First launch is refused: Settings → General → VPN & Device Management → your Apple ID → Trust.
7. A free-team build expires after 7 days; press Run again to renew. Max 3 apps per device.

Sign in with Apple and in-app purchases need the paid Apple Developer Program; everything else
runs on a free team.

## Performance probe

Projects screen → account menu → **Performance probe**. Open a canvas: an overlay shows

- time to canvas revealed (`[data-canvas-surface][data-revealed="true"]`) and interactive (next
  frame), in ms since navigation start;
- fps over the last second and the minimum since reveal (pan, zoom or play to load it);
- long frames (> 50 ms) and the worst frame;
- JS heap (`performance.memory`; WebKit does not expose it, so it reads n/a on iOS);
- app memory footprint (`task_vm_info.phys_footprint`, the number jetsam kills on). The WebView's
  content process is separate and not included;
- web content process terminations and the reloads that recovered them.

**Copy** puts the report on the clipboard. The same footprint is exposed to the page as the
Capacitor plugin `FeegaPerf.footprint()`.
