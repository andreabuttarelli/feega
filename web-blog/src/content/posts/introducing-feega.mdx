Design and code live in different places. You adjust a padding in a design tool, someone translates it into code, and details get lost on the way. Or you ask an agent for a change as small as four pixels and wait for a prompt to come back.

Feega closes that gap. It is a free, open-source VS Code extension to **design in your codebase.**

This post first went up on 27 October, when Feega was a different product: a canvas with motion and AI generation. We removed all of it on 20 November. [Why Feega is now one thing](/posts/design-in-your-codebase/) tells that story. What follows describes Feega as it is today.

## How it works

Run your app through Feega and click an element. Edit it in the right bar: text, size, spacing, layout, colour, gradients, radius, shadows, typography and position. The preview updates, and so does the file.

Feega starts your dev server and, in development only, tags each element with the file, line and column it came from. A click on the page lands on a line of source.

## The change is a diff

Feega writes the edit the way you would, in the system your project already uses: a Tailwind class, a rule in a CSS module, a scoped style. Every edit shows up in Changes, where you can review it, undo it or revert it.

There is no AI in the loop, no tokens and no account needed. It sits next to the agent you already use: you adjust, your agent codes, same files.

## What you can do

- **Layers.** The element tree of your page. Select from it, reorder siblings, hide or lock rows.
- **Breakpoints.** Pick full, desktop, tablet or phone width. In a Tailwind project the edit goes to the class that applies at that width.
- **Changes.** Every edit as a diff in your source.
- **Plugins.** A mesh gradient that writes plain CSS, a 3D object you place on an element, and more. You choose which ones are on, and each lists the permissions it asks for.
- **Templates.** A free [library of sections, components and app screens](https://www.feega.app/templates), each in Svelte, React, Vue, Astro and HTML.

## What it works with

React and Next.js, Vue and Nuxt, Svelte and SvelteKit, Astro, React Router and Vite, styled with Tailwind, CSS modules, scoped styles or plain CSS. It runs in VS Code, Cursor, Windsurf and VSCodium on macOS, Windows and Linux, or in any browser with `npx feega`.

It does not write everything. Class names built by an expression, and text that comes from data rather than markup, are refused with a message that points at the line. The [docs](https://docs.feega.app) list the limits per framework.

## Open source

Feega is Apache-2.0. You can read how it works, follow what we build, open an issue or send a pull request. The code is on [GitHub](https://github.com/andreabuttarelli/feega).

Feega Cloud is planned for later. The extension stays free. See [pricing](https://www.feega.app/pricing).

## Try it

Install it from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=andreabuttarelli.feega), or [Open VSX](https://open-vsx.org/extension/AndreaButtarelli/feega) for Cursor, Windsurf and VSCodium. Or run this in your app folder:

```bash
npx feega
```

The [docs](https://docs.feega.app) have a quick start and a page per framework. If you want to talk to us, or show what you made, join us on [Discord](https://discord.gg/PUp37DG6vr).

We are building Feega in public, and this blog is where we write about it.
