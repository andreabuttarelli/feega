---
title: CSS modules
description: How Feega writes edits in React and Next.js projects that use CSS modules.
sidebar:
  order: 3
---

In React and Next.js without Tailwind, Feega writes a rule in the CSS module next to the component. If the module is not imported yet, Feega adds the import.

The element gets a class from the module, and the rule holds the edited properties.
