The Fill section holds a list of layers. Add a layer with the plus button. Each layer is a solid colour, a gradient or an image.

- **Colour**: pick with the colour picker or type a hex value.
- **Gradients**: edit the stops and the angle.
- **Images**: see [Images](/editing/images/).

Text colour in Typography uses the same layers, so text can have a gradient fill.

Fills are written as `background` properties, or as the matching Tailwind classes when the project uses Tailwind. If your theme has a token for the colour, Feega uses the token.
