title: Position and size
description: Size, spacing and position of an element.
sidebar:
  order: 6
---

- **Size** sets width and height, with min and max.
- **Spacing** sets padding and margin.
- **Position** sets the position type, the offsets and the z-index. Constraints and flex-child options appear when the element sits in a layout that uses them.

Each field accepts a typed value or a drag. Values are written in the project's [styling system](/styling/tailwind/): in Tailwind, an arbitrary value is used when no utility matches.
