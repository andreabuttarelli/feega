The right bar shows the sections that make sense for the selected element. A text element gets Typography first. A container gets Auto layout. An image gets Object. An icon gets Icon. Page and head elements are not edited.

| Section | What it edits |
|---|---|
| Size | Width and height, with min and max. For icons, width and height can be linked. |
| Spacing | Padding and margin. |
| Auto layout | Display, direction, gap, alignment, wrap. Grid has its own section. |
| Typography | Font, weight, size, line height, letter spacing, alignment, decoration, colour. See [Text](/editing/text/). |
| Fill | Colour layers, gradients, images. See [Fills and gradients](/editing/fills-and-gradients/). |
| Radius | Corner radius. |
| Border | Width, style and colour. |
| Effects | Shadows (several), opacity. |
| Position | Position, offsets, z-index. See [Position](/editing/position/). |
| Object | How an image or video fits its box. |
| Icon | Swap or search an icon. |
| Stroke, Filters, Transform, Transition, Cursor | Finishing properties. |

Number fields can be dragged to scrub the value, or typed. A reset button clears a value you set. Inherited values are marked with where they come from.

Every change is written to your source in the project's [styling system](/styling/tailwind/).
