Right-click an element, on the page or in Layers, for the structure menu.

| Action | Shortcut (macOS) |
|---|---|
| Duplicate | `⌘D` |
| Wrap in container | `⌘G` |
| Unwrap | `⇧⌘G` |
| Delete | `⌫` |

## Add

Add a new element next to the selection: Text, Heading, Button, Link, Image or Container.

## Reorder

Drag a layer in the tree, or an element on the page, to change its place among its siblings.

## Limits

- Elements generated by a loop (`{#each}`, `v-for`, `.map`) share one source line, so they cannot be moved one by one.
- Every structure change is a source edit and can be undone.
