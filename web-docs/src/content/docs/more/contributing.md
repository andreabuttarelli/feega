Feega is free and licensed under Apache-2.0.

- Code and issues: [github.com/andreabuttarelli/feega](https://github.com/andreabuttarelli/feega). The extension is in `inspect/`, `npx feega` in `npx/`.
- Pull requests go to the `dev` branch. `main` receives batched releases.
