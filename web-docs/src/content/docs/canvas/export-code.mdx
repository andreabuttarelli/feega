**Export code** turns a whole frame, with every nested frame, text, image, vector and component instance inside it, into a project a developer can keep. It is static: animation is not exported yet.

## Use it

1. Select a frame on the canvas.
2. Open the **…** menu and choose **Export code…**.
3. Pick a target: **React + Tailwind** (default), **HTML + CSS** or **SvelteKit**.
4. Click a file to read it, **Copy file** to copy it, **Download .zip** for the whole project.

## What you get

| In the design | In the code |
|---|---|
| Auto layout (horizontal, vertical) | `display: flex` with `gap`, padding, alignment and wrap |
| Auto layout grid | `display: grid` with its columns (`grid-cols-12`) and column/row spans |
| Fill, hug, fixed sizing | `flex: 1`, `align-self: stretch`, no size, or a width (fluid with `max-width` from 320 px) |
| A frame without auto layout | `position: relative`, its layers `position: absolute`, pinned by their constraints |
| Components and instances | one file per component; text, images, colours and visibility that differ between instances become typed props |
| Text | `h1` for the largest heading on the page, then `h2`/`h3` by size and weight, `p` for body copy, `a` for linked text |
| Layers named Nav, Header, Footer, Hero, Features, Pricing, Card… | `nav`, `header`, `footer`, `section`, `article` |
| Components named Button or Link | `button type="button"` and `a href` |
| Colours, fonts, radii, spacing | a tokens file (`@theme` for Tailwind, CSS variables otherwise); colour variables keep their names |
| Images | `img` pointing at the image URL at export time |
| Vectors, polygons, stars | inline `svg` |

Class names come from layer names (`Feature card` becomes `FeatureCard` and `.feature-card`), and the same frame always gives the same files.

## What does not map

- Effects with no CSS equivalent (noise, displacement, chromatic aberration…) are left out and listed under **Not exported**. Drop shadow, inner shadow, layer blur and background blur are kept.
- Shaders, 3D, particles, video effects and timing are not exported.
- A frame without auto layout stays absolutely positioned: it does not reflow on a phone. Add auto layout before exporting for responsive code.
- Overrides of an instance nested inside another component are not passed down as props.
- Image URLs from your project are signed and expire: download the files into the project before shipping.

## From the CLI and agents

```bash
feega motion code <nodeId> --target svelte --out ./site
```

The `export_code` MCP tool returns the same files as JSON, free and without AI:

```json
{ "node_id": "<frameId>", "target": "react" }
```

```json
{ "name": "Landing", "target": "react", "files": [{ "path": "src/components/Button.tsx", "content": "…" }], "notes": [] }
```

The endpoint behind both is `GET /api/v1/motion/{nodeId}/code?target=react|html|svelte`.
