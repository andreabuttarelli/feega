## Search

- Press `Cmd F` (`Ctrl F` on Windows and Linux) to open the search bar.
- Type a name, a word from the text, or a word from a prompt.
- Move through the results with the arrow keys. `Enter` jumps to the node and selects it. `Esc` closes the bar.

## Colour tags

- Select one or more nodes and pick a colour in the toolbar.
- The same colours sit under the search field. Click one to show only nodes with that tag. Click it again to clear the filter.
- Combine text and colour to narrow the results.
