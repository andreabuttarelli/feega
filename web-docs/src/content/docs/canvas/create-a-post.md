---
title: Create a post
description: Turn selected nodes into a post.
sidebar:
  order: 18
---

Select one or more nodes (text, images, video) and use **Create post** in the selection bar. The composer opens with the chosen material inside; a linked text node enters as writable material, not just a fixed caption.

A node already used in at least one post shows a small dot on its tile, titled "Used in a post" on hover.

From the composer, save the post as a draft, or approve and schedule it for a date. A post belongs to the brand, not the canvas: once created it appears in that brand's calendar, whichever canvas generated it.
