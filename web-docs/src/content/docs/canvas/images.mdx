- **Fill modes:** Fill, Fit, Stretch, Crop and Tile, with tile scale and rotation.
- **Crop:** double-click an image fill, or press Crop image in Properties. Drag to move the picture, drag a corner to scale, `Enter` to apply.
- **Adjustments:** exposure, contrast, saturation, temperature, tint, highlights and shadows. Identical on the canvas and in exports.
- **Remove background:** select an image and remove its background in one click.
- **Upscale:** 2× or 4× from the same toolbar; the result lands in a new node beside the original.
- **Generation history:** the Assets panel has a History tab with every finished generation across projects, filterable by model.
- **Shared library:** save any asset to your organization library and use it from every project.

## Compare and pin generation versions

<DemoVideo name="compare-run-versions" caption="Pick two versions of an image node, slide between them and read what changed." />

An image node keeps every result it has generated. Compare two of them to see what changed, or pin one as the node output.

1. Select an image node that has at least two results. The history button (a grid icon with the result count) appears in the node toolbar.
2. Click it. The popover lists every version.
3. Click a version to pin it as the node output. Reruns and nodes downstream use the pinned version.
4. To compare, press **Compare**, then click two versions.
5. The compare view opens: drag the slider to wipe between version A and B. Below it a table lists only what differs: prompt, model and each setting (aspect, style and so on). If nothing differs it says so.
6. Press Esc to close.

Compare works on image nodes. Pinning works on every medium.

### From an agent, MCP or CLI

The same actions are canvas ops, called with `canvas_tool`:

- `list_runs` lists the runs of a node.
- `compare_runs` returns the fields that differ between two runs.
- `show_run` pins a past run as the node output.

```json
{ "op": "compare_runs", "input": { "nodeId": "<node id>", "runA": "<run id>", "runB": "<run id>" } }
```

Result: `a` and `b` (run id, asset id, prompt, model, params, cost) and `diff`: `[{ "field": "prompt", "a": "... soft morning light", "b": "... hard noon light" }, { "field": "style", "a": "natural", "b": "studio" }]`.
