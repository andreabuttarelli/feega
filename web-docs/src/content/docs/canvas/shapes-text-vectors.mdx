## Shapes and vector tools

| Key | Tool |
|---|---|
| `R` / `O` | Rectangle / ellipse |
| `L` / `Shift+L` | Line / arrow |
| `P` | Pen: click points, drag for curves |
| `Shift+B` | Pencil: freehand, smoothed into editable paths; hold Shift for straight segments |
| `X` | Shape builder: merge regions of overlapping shapes, Alt-click to remove one, Enter to apply |
| `K` | Scale tool: scales size, text, strokes and effects together |

Rotate by dragging just outside a corner (Shift snaps to 15 degrees). `Alt+R` shows the rotation origin so you can move it. Gradients can be linear, radial, angular or diamond.

Colour fields accept hex with or without `#` (`f`, `ff` and `fff` all mean white; 4 and 8 digits carry opacity), `rgb()`/`rgba()`, or bare numbers such as `255, 0, 0` or `255 0 0 50%`. Opacity typed this way sets the fill's opacity. Anything else leaves the colour unchanged.

## Colour picker

Every colour in the editor opens the same picker: fill, stroke, text colour, effects, background, guides, shared styles and variables.

<DemoVideo name="figma-colour-picker" caption="Pick a colour, switch to RGB, sample with the eyedropper and reuse a swatch." />

- A fill opens with the saturation and brightness square already showing. Drag in it, or focus it and use the arrow keys (Shift moves by 10).
- A hue slider and an opacity slider sit under the square; opacity has a checkerboard behind it.
- The eyedropper samples any pixel on screen. It shows only in browsers that support the EyeDropper API.
- The format menu switches the value fields between Hex (one field), RGB, HSL and HSB (three fields), with an opacity percentage next to them. Arrow keys nudge a number; Shift nudges by 10.
- Swatches list the colours already used in the document, the brand colours and the ones you picked recently.
- A fill popover keeps the paint type (Solid, Linear, Radial, Angular, Diamond, Image) at the top. A gradient stop uses the same picker.
- Dragging updates the canvas live and counts as one undo step.

Colours are still stored as `#rrggbb` (or `#rrggbbaa`) or a brand token, so scripts, the CLI and agents read and write them as before.

A shape can morph into any other shape, including hand-drawn paths and shapes with holes.

## Text

- Select any part of a text and style it: bold, italic, size, colour, gradient, underline or strikethrough (solid, double, dotted, dashed, wavy), small caps, OpenType features.
- Links: `Shift+Cmd+U`. Lists: `Shift+Cmd+8` bulleted, `Shift+Cmd+7` numbered, `Tab` to nest.
- Auto width and auto height text grows as you type.
- Turn text into editable vector shapes with `Shift+Cmd+O`.
- Replace a missing or unwanted font in the whole video in one pick.
