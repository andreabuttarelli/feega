## Shapes and vector tools

| Key | Tool |
|---|---|
| `R` / `O` | Rectangle / ellipse |
| `L` / `Shift+L` | Line / arrow |
| `P` | Pen: click points, drag for curves |
| `Shift+B` | Pencil: freehand, smoothed into editable paths; hold Shift for straight segments |
| `X` | Shape builder: merge regions of overlapping shapes, Alt-click to remove one, Enter to apply. Open it from the command palette or the key; it is no longer in the bottom bar |
| Add bar, Stack | Draw an empty stack: a transparent rectangle with vertical auto layout that hugs what you drop in |
| `K` | Scale tool: scales size, text, strokes and effects together |

The kind of a shape is chosen once, when you draw it: Properties has no Shape switcher. Start, sweep and ratio appear only on an ellipse, sides only on a polygon, points and inner radius only on a star. To get another kind, draw it and delete the old one.

A shape drawn over a frame lands inside that frame; drawn on empty canvas it stays free. Either way it shows the moment you release, and saves in the background.

Rotate by dragging just outside a corner (Shift snaps to 15 degrees). `Alt+R` shows the rotation origin so you can move it. New layers rotate and scale around their centre. Gradients can be linear, radial, angular or diamond; their handles show on the canvas while that fill is open in the Fill section.

A selected line shows a handle at each end instead of a box: drag one to move that end, hold Shift to snap the line to 45 degrees.

X and Y keep decimals, shown up to two. A fill with no colour reads **None** over a checkerboard. With a layer selected, hovering the empty part of its frame highlights the frame.

Colour fields accept hex with or without `#` (`f`, `ff` and `fff` all mean white; 4 and 8 digits carry opacity), `rgb()`/`rgba()`, or bare numbers such as `255, 0, 0` or `255 0 0 50%`. Opacity typed this way sets the fill's opacity. Anything else leaves the colour unchanged.

## Colour picker

Every colour in the editor opens the same picker: fill (text included), stroke, effects, background, guides, shared styles and variables.

- A fill opens with the saturation and brightness square already showing. Drag in it, or focus it and use the arrow keys (Shift moves by 10).
- A hue slider and an opacity slider sit under the square; opacity has a checkerboard behind it.
- The eyedropper samples any pixel on screen. It shows only in browsers that support the EyeDropper API.
- The format menu switches the value fields between Hex (one field), RGB, HSL and HSB (three fields), with an opacity percentage next to them. Arrow keys nudge a number; Shift nudges by 10.
- Swatches list the colours already used in the document, the brand colours and the ones you picked recently.
- New elements start in plain colours: shapes `#D9D9D9`, text and strokes `#000000`, frames `#FFFFFF`. Brand colours apply only when you pick one from the **Brand** swatches, which show the project's brand (or the workspace's first brand) with each name on hover.
- A fill popover keeps the paint type (Solid, Linear, Radial, Angular, Diamond, Image) at the top. A gradient stop uses the same picker.
- Gradient stops work from the keyboard: Tab to a stop, arrow keys move it by 1% (Shift by 10%), Home and End send it to the ends, Delete removes it while more than two remain. **+** next to Position adds a stop in the middle of the widest gap; a click on the bar adds one where you click.
- Enter in a hex, channel or opacity field applies the value and keeps the field focused.
- Dragging updates the canvas live and counts as one undo step.

Colours are still stored as `#rrggbb` (or `#rrggbbaa`) or a brand token, so scripts, the CLI and agents read and write them as before.

## Combining shapes

Select two or more shapes and pick **Union**, **Subtract**, **Intersect** or **Exclude** in Properties. The result is one shape named after the operation, boxed tightly around what is left, without the strokes of the originals. Subtract cuts the shapes in front out of the one at the back. `Cmd+Z` brings the originals back.

## Editing points

Double-click a selected shape, or press `Enter`, to edit its points. Rectangles, ellipses, polygons, stars and lines become free paths when you do.

<DemoVideo name="vector-edit" caption="Double-click a shape, move a point, bend a curve." />

| Action | Result |
|---|---|
| Drag a point | Moves it (snaps to the frame and other layers; hold `Cmd` to skip snapping) |
| Drag a handle | Bends the curve; the opposite handle mirrors it |
| `Alt`/`Option` + drag a handle | Moves one handle only, breaking the symmetry |
| Double-click a point (or `Alt`-click) | Toggles it between sharp and smooth |
| Click the outline | Adds a point |
| `Delete` | Removes the selected point |
| `Esc`, `Enter` or click outside | Leaves point editing |

Moving a point outside the layer's box grows the box to fit, so X, Y, W and H always match the path. Each change is one undo step. The chat agent edits points the same way with `edit_path_points`.

A shape can morph into any other shape, including hand-drawn paths and shapes with holes.

## Text

- Select any part of a text and style it: bold, italic, size, colour, gradient, underline or strikethrough (solid, double, dotted, dashed, wavy), small caps, OpenType features.
- Links: `Shift+Cmd+U`. Strikethrough: `Shift+Cmd+X`. Lists: `Shift+Cmd+8` bulleted, `Shift+Cmd+7` numbered, `Tab` to nest. Typing `- ` or `1. ` at the start of a line starts a list too.
- Undo while typing steps back a word at a time, as in Figma; a pause or a switch between typing and deleting starts a new step.
- Auto width and auto height text grows as you type.
- A size applies exactly as typed. Auto width and auto height text grows with it; fixed-size text overflows its box and is never shrunk.
- Weight steps in hundreds, 100 to 900: scrubbing, arrow keys and typed values snap to the nearest 100.
- Case is five icon buttons: as typed, uppercase, lowercase, title case and small caps. Hover for the name.
- With a text selected, Properties reads top to bottom: alignment, X/Y, rotation, W/H with the aspect lock at the end of the row, Appearance, **Typography**, Fill, Stroke, Effects.
- In Layout, above W/H, pick **Auto width**, **Auto height** or **Fixed size**; W and H show **Hug** or **Fixed** accordingly.
- Font size has a presets menu: 12, 14, 16, 20, 24, 32, 48, 64, 96.
- In Typography, line height and letter spacing are percentages of the font size: 130% line height, -2% letter spacing.
- Width axis, slant axis and other variable-font axes sit under a collapsed **Advanced** row in Typography.
- An uploaded **variable font** (TTF, OTF, WOFF or WOFF2 with a weight axis) is one file for every weight: pick any weight in its range and the editor and exports draw it.
- Turn text into editable vector shapes with **Outline text** (`Shift+Cmd+O`). The outlines come from the same font file and layout the canvas draws with: family, weight, italic, size, letter spacing, line height, alignment, line breaks, kerning and ligatures stay exactly where they were. Fill, stroke, opacity and transform carry over; per-word colours and text animations do not.
- Replace a missing or unwanted font in the whole video in one pick.
