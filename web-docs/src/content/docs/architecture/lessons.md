[`LESSONS.md`](https://github.com/andreabuttarelli/feega/blob/main/LESSONS.md) holds lessons from real incidents, one section per theme: the signal that lets you recognise the failure, and the move that solves it. It is long (over 3,000 lines) and mostly in Italian, so it is linked here, not copied.

Read it before diagnosing something strange: stale `node_modules` after a rebase, a full-suite flake versus a true defect, a closed PR that looks like API lag, Docker on macOS hanging when the clone lives in `~/Documents`.

A new lesson goes in the same commit that paid for it.

Also in the repo: `CONTRIBUTING.md`, `SECURITY.md`, and `DESIGN.md` (the visual rules for the app and the videos).
