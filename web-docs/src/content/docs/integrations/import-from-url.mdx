Paste the address of a public web page and Feega draws it as a frame you can edit: text stays text, flex rows and columns become stacks, backgrounds, borders, corners and shadows become fills, strokes and effects, pictures are copied into your project, inline SVG icons become vector paths. It is not a screenshot.

## In the app

Open the insert menu (**+**), go to **Import**, choose **From URL…**, paste the address and press **Import**. The frame lands in the middle of the view, named after the page title.

## Limits

- Public `http`/`https` pages only. Private network addresses and pages behind a login are refused.
- The page is read at desktop width (1280 px), down to 3840 px from the top, up to 1500 layers.
- Fonts that Google Fonts does not have fall back to Inter.
- Four imports a minute per person.
- Not yet: tablet and phone layouts as breakpoints, gradients.

## Components

Blocks the page repeats (cards, logos, buttons, list items) become one main component and linked instances. Each instance keeps its own text, pictures and colours as overrides, so editing the main updates every copy and **Reset** brings one back to the main. Blocks with the same structure but a different background, border or shadow become variants of one component (`Style=Primary`, `Style=Secondary`). Names come from what the block is: button, card, feature card, nav link, logo. Find them in the **Components** panel.

A block is turned into a component when it repeats at least twice, is at least 16 px on each side and has a background, a picture or an icon. Sidebar rows, nav links and buttons inside auto layout rows count too. Copies of a different size, or with a different icon or spacing, stay linked: the difference is an override on that instance, as in Figma. Each component shows a preview of itself in the **Components** panel.

## CLI

```bash
feega canvas import-url $PROJECT https://example.com --canvas <canvas> --x 0 --y 0
```

`x` and `y` are the canvas position of the frame centre. The answer has `frame_id` and `truncated` (true when the page hit the layer or height cap).

## MCP and API

Over MCP: `canvas_tool({ project_id, op: "import_url", input: { canvasId, url, x, y } })`.

Over HTTP: `POST /api/v1/projects/{projectId}/url-import` with `{ canvasId, url, x, y }`. Errors: `not_public` (400), `failed` (502, the page answered with an error), `unreadable` (422), `rate_limited` (429), `no_browser` (503).
