[Ruixen UI](https://ruixen.com) is a React and Tailwind component library for shadcn projects. Its free, open-source components (MIT) ship with Feega as the **Ruixen** group of the component library: 197 components, from buttons, inputs and navbars to pricing tables, heroes and footers, each as editable layers.

## Insert a component

- **In the app**: on the canvas open **+** → **Components**, pick the **Ruixen** group, choose a component and press **Add to canvas**. Inside a composition, **Use in composition** places it there.
- **Agents**: Ruixen components are templates with ids `builtin:ruixen-<name>` (for example `builtin:ruixen-pricing-plans`). The motion and project agents list them with the other components and insert them by id; the API lists them at `GET /api/v1/motion/templates`.

## Animation

Many Ruixen components move: marquees, counters, reveals, scroll effects, WebGL backgrounds. Feega imports each one in its settled state, as a still of editable layers: transitions are skipped to their end before the import reads the page. Animations drawn on a `<canvas>` or advanced by a timer are read at whatever frame they show. The animation itself is not carried over; animate the layers on the canvas timeline if you need motion.

## What is and is not included

Only the components of Ruixen's open-source repository are included, pinned to one commit in the Feega repository. Ruixen Pro (the paid templates and premium components on pro.ruixen.com) is not fetched or stored. Of the 212 free components, 197 are included. 5 are left out because they need the Next.js runtime or files the registry does not ship. 10 more do not come in as a component of their own yet: 2 only show after a click or a scroll, 8 are folded into the example around them.

Images in the components (logos, avatars, photos) load from Ruixen's public repository and image hosts at the pinned commit, so they need a connection. Effects built on 3D perspective or CSS masks (coverflow carousels, tilted mockups) come in flat, and some appear as a grey placeholder.
