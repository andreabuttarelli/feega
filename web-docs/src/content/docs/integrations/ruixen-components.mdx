[Ruixen UI](https://ruixen.com) is a React and Tailwind component library for shadcn projects. Its free, open-source components (MIT) ship with Feega as the **Ruixen** group of the component library: 159 components, from buttons, inputs and navbars to pricing tables, heroes and footers, each as editable layers.

## Insert a component

- **In the app**: on the canvas open **+** → **Components**, pick the **Ruixen** group, choose a component and press **Add to canvas**. Inside a composition, **Use in composition** places it there.
- **Agents**: Ruixen components are templates with ids `builtin:ruixen-<name>` (for example `builtin:ruixen-pricing-plans`). The motion and project agents list them with the other components and insert them by id; the API lists them at `GET /api/v1/motion/templates`.

## Animation

Many Ruixen components move: marquees, counters, reveals, scroll effects, WebGL backgrounds. Feega imports each one as it looks once it has settled on screen, a still frame of editable layers. The animation itself is not carried over; animate the layers on the canvas timeline if you need motion.

## What is and is not included

Only the components of Ruixen's open-source repository are included, pinned to one commit in the Feega repository. Ruixen Pro (the paid templates and premium components on pro.ruixen.com) is not fetched or stored. Of the 212 free components, 5 are left out because they need the Next.js runtime or files the registry does not ship, and 48 do not appear as their own component yet: they render through parts with other names (drawers, sheets, dialogs) or only show after an interaction.
