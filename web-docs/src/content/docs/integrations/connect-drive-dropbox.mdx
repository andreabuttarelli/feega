Google Drive and Dropbox are the two cloud providers. Each person connects their own account, and files never move without a click.

## Connect

You connect from the picker, there is no settings page.

1. On the canvas, switch the bottom bar to **Design** (the pen icon on the left of the bar).
2. Choose the cloud icon, **Drive / Dropbox**.
3. Pick the **Google Drive** or **Dropbox** tab and choose **Connect**.
4. Sign in with the provider and approve access. You land back on the canvas with the picker ready.

feega asks for:

| Provider | Access |
| --- | --- |
| Google Drive | Read your files, and create files it exports |
| Dropbox | Read file metadata and content, write files |

Access is offline, so the connection stays until you revoke it. Tokens are stored encrypted, per person, and refreshed when they expire.

## Import

1. Open the picker as above and choose the provider tab.
2. Open folders with a click. The path at the top goes back up.
3. Choose a file. It lands on the canvas at the middle of your view, as an image, video or document node, and is selected.

Drive lists up to 200 entries per folder. Google Docs, Sheets and Slides are not converted; pick regular files such as images, video and PDFs.

## Export

1. Select one image or video node.
2. In the selection bar, open the cloud menu and choose **Export to Google Drive** or **Export to Dropbox**.
3. Open the destination folder and choose **Export here**. In Google Drive, open a folder first.

The file keeps the name it has in the project's storage. Dropbox renames on a clash, so nothing is overwritten.

## Disconnect

There is no disconnect button in feega yet. To cut access, revoke feega in the provider: Google account, Security, third-party access; or Dropbox, Settings, Connected apps. The next import or export asks you to connect again.

## Troubleshooting

| What you see | Why | Fix |
| --- | --- | --- |
| "Connect Google Drive to continue." | No connection, or the connection expired or was revoked | Choose **Connect** |
| "Google Drive is not set up on this server." | Self-hosted without the provider's app credentials | Set `GOOGLE_DRIVE_CLIENT_ID` and `GOOGLE_DRIVE_CLIENT_SECRET` (or `DROPBOX_CLIENT_ID` and `DROPBOX_CLIENT_SECRET`), with `/api/v1/cloud/callback` as the redirect URL |
| "Could not load files." | The provider refused the listing | Reconnect, then retry |
| "Import failed", `download_failed` | The provider refused the download | Check you can open the file in the provider |
| "Export failed" | The provider refused the upload, or the asset could not be read | Pick a different folder |
| The cloud icon is missing | Local mode hides cloud controls | Use the hosted app |

## CLI, MCP and API

There is no CLI command or MCP tool for cloud files yet. The REST endpoints behind the picker, all under `/api/v1/projects/{projectId}/cloud/{provider}` with `provider` set to `google_drive` or `dropbox`:

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/files?folder=` | List a folder |
| `POST` | `/import` | `{ fileId, place: { canvasId, x, y } }` |
| `POST` | `/export` | `{ assetId, folder, name? }` |

They answer `409` with `not_connected` or `reconnect`, and `501` with `not_configured`. Connecting is always the browser flow at `/api/v1/cloud/{provider}/connect`.
