## Supported

- Astro 5. Select, text, style and structure edits are tested on macOS, Linux and Windows.
- Edits are written to the `.astro` file. Style edits go to the page's style block.

## Limits

- Feega must start the dev server. Attaching to an Astro server you already started does not map elements to source.

## Free templates

Free sections and UI components to start from, in Astro: [Feega templates](https://www.feega.app/templates/astro).
