A technique is a connected group of generation nodes saved under a name. Its open inputs become slots (text, document or image), its last nodes the outputs.

## Run it on a list

<DemoVideo name="technique-on-a-list" caption="Place a technique, paste three product names, see the cost. The video stops before Start: nothing is spent." />

Place the technique from **Templates** (your techniques are listed there). Select its node, then right-click it and choose **Run on a list…**.

1. Paste one row per line, or a CSV (commas or tabs), or load a CSV file. Up to 50 rows.
2. Map columns to the technique inputs. By default the columns fill the inputs in order. An image input takes an image URL.
3. **See the cost** shows the credits for all rows before anything starts.
4. **Start** writes one output group per row on the *Technique runs* canvas and queues them. Progress shows done and failed rows; **Stop the rest** cancels the rows not started yet.

### From an agent, MCP or CLI

| Op | Spends | Input |
|---|---|---|
| `preview_technique_rows` | no | `techniqueId`, `rows` (one array of cells per row, 50 at most), `mapping?` |
| `run_technique_rows` | yes | same as the preview |
| `technique_rows_progress` | no | `runIds` from the start |
| `cancel_technique_rows` | no | `workflowIds` from the start |

`mapping` has one entry per input slot of the technique: the index of the cell it takes, or `null`. Without it the slots take the cells in order. Image slots take a URL. Always preview first:

```bash
feega canvas $PROJECT preview_technique_rows --input '{"techniqueId":"<id>","rows":[["Ceramic mug"],["Linen tote bag"],["Walnut desk lamp"]]}'
```

The answer holds `rows`, `creditsPerRow` and `credits`. Ask the person before `run_technique_rows`.
