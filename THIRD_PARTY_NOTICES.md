# Third-party notices

No third-party source code is vendored in this repository. The extension build bundles `modern-screenshot` (MIT, Copyright (c) qq15725) as `capture-lib.js`, the page-side screenshot used by the AI chat; it is fetched from npm at build time. One data list is vendored: see Disposable email domains. Fonts keep their licence files next to them in `static/fonts/`.

## Inter Bold

`packages/plugin-object-3d/src/runtime/inter_bold.typeface.json` is Inter Bold (Latin subset) converted to three.js typeface JSON by `packages/plugin-object-3d/scripts/make-font.mjs`. Copyright (c) 2016 The Inter Project Authors, SIL Open Font License 1.1, no Reserved Font Name. The licence is `packages/plugin-object-3d/src/runtime/OFL.txt`, and the 3D object plugin writes it next to the font in the user's project.

## Disposable email domains

`src/lib/server/email-policy/disposable-domains.json` and `scripts/sql/seed-disposable-email-domains.sql` are generated by `scripts/refresh-disposable-domains.mjs` from the `disposable-email-domains` project's blocklist (https://github.com/disposable-email-domains/disposable-email-domains), released under CC0 1.0 (public domain dedication).

The earlier version of Feega, which vendored code from OpenPencil, snapcn, Paper Shaders, Magic UI, Animata, free-remotion-templates, Arc and Ruixen UI, was removed on 20/11/2026. Its notices remain in the git history and in the archive `feega-20261120.bundle`.
