## Annex 1 — Technical and organisational measures

Tenant isolation

Measure: each customer’s data is logically separated and access is enforced by the database for every request

Access control

Measure: role-based access inside each workspace; privileged administrative access limited to what operating the Service requires and restricted to authorised personnel

Authentication

Measure: secure session management; API keys stored hashed and revocable

Encryption

Measure: encryption in transit (TLS) for all connections; encryption at rest provided by our infrastructure providers

Storage

Measure: uploaded and generated files kept private and served through time-limited links; share links read-only and revocable

Logging and monitoring

Measure: logging of AI actions, moderation decisions and changes to content; error monitoring

Content safety

Measure: automated screening of generation requests (see AI Transparency)

Availability

Measure: backups and recovery provided by our infrastructure providers [BACKUP POLICY]

Secrets

Measure: credentials held server-side only and excluded from logs

Development

Measure: code review and automated testing before release; production data not used in testing

People

Measure: confidentiality obligations; least-privilege access [to confirm organisational measures]
