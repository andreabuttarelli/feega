# Feega for Claude Code

Design in your codebase. This plugin gives Claude Code a skill to set up a web project for [Feega](https://www.feega.app), start the visual editor, and write markup Feega can edit back into source.

Install:

```
/plugin marketplace add andreabuttarelli/feega
/plugin install feega@feega
```
