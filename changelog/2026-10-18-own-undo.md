# Canvas undo takes back only my own fields

Undoing a node edit was refused (`node_changed_by_peer`) as soon as anyone
had written the node since, even on a different field. Figma instead
reverts the user's own properties and leaves the rest.

Now `checkGesture` builds the inverse of a `node.update` from the node's
current data (`ownKeysBack`): every key whose current value still equals
my `after` goes back to my `before` (or is removed if it did not exist);
a key a peer has overwritten since is theirs and is left alone. The write is
a merge (`patch_node_data` → `patchNodeData`), not a whole-data rewrite at
an expected version. An item whose keys were all overwritten writes
nothing and is not a refusal. The version check stays for frame
revisions (`doc.revision`), which are whole documents.
