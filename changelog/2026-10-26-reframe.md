# Reframe to another aspect (T9)

Image and video nodes get **Reframe…** (9:16, 1:1, 4:5, 16:9, custom w:h).

- Image: `image_tool` gains `reframe` {aspect}. `lib/reframe.ts` derives the even `extend` from the
  picture size, then the outpaint path (`paddedPlan` in `image-tool.ts`) pads and masks. Same
  model as outpaint; a default prompt asks to continue the scene. Gated like every image tool.
- Video: no catalogue model reframes video (Kie, Wiro, Higgsfield checked: none). Fallback is an
  ffmpeg crop around a focus point (`video-reframe.ts`, op `video_reframe`), free, no gate.
  There is no saliency detector in the repo, so the focus is chosen by the user (default centre),
  not detected. Discarded: a new detector dependency.
- Wiring: `ReframeDialog` -> `reframe()` in the canvas page -> `imageTool` / `videoReframe`
  actions -> `startImageTool` / `startVideoReframe`. Parity: `reframe` and `videoReframe` map to
  canvas ops. MCP text updated.
- Limit: `extend` per side is not capped for reframe, so extreme aspect jumps ask the model for a
  very large fill. Unverified against a real call (no paid generations in this change).
