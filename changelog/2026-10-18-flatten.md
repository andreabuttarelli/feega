# Flatten

⌘E (Layer menu: Flatten) merges the selected shapes into one path on the
bottom one, which keeps its style; the others go. One shape alone becomes an
editable path of the same outline. Unlike the booleans it does not clip: each
outline is carried over as it is, mapped through `pathSpace` with `mapOutline`,
so curves stay curves instead of the 16-sample polylines a boolean leaves.

Agent: `combine_shapes` op `flatten` (one or more clips); the tool's ops now
come from one table (`SHAPE_OP`). No new tool name.
