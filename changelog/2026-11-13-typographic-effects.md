# Typographic effects, effect and composition templates

Four builtin effects (`src/lib/canvas/effects/typo/`): word-weave, word-field, glyph-tiles,
word-silhouette. They are CPU `Pixels` passes like every builtin, so the canvas preview, the editor
and the server video export (`video-effects.ts`) run the same code.

- Glyphs come from a baked Fragment Mono alpha atlas (`typo/glyph-atlas.ts`, regenerated by
  `scripts/effects/glyph-atlas.mjs`). One font only: a second font is a second atlas.
- Sizes are relative to a 1080 px side (`unit`), so the 480 px preview matches a full-res export.
- Time: `applyStack` takes `time` and an optional `StackMemory`. With memory (video preview,
  export) each cell keeps its word until its luminance moves past `sensitivity`, then
  crossfades; weave fragments use hysteresis; a column/row profile match tracks global pan and
  words move with it. Without memory (stills) choice is a pure function of quantised luminance
  plus optional looped noise. The first version reshuffled on a clock and looked chaotic.
- New param kind `text` (word lists): zod schema in `node-data.ts`, `TextField` control.
- `EffectDefinition.description` feeds `list_effects`, so the agent knows when to pick each look.
- `CANVAS_TEMPLATES` gains categories `effects` (9 looks, image → effects node) and
  `composition` (one per layout, generated from `LAYOUTS`). Thumbnails from
  `scripts/effects/template-thumbs.ts`.
- `/app/templates` reads the same list for composition and effects next to the motion shelves,
  with a family filter; "use in new canvas" is the `fromCanvasTemplate` home action.
- 1080p frame cost on an M-series laptop: 9–16 ms per look.
