# Rich text: styled ranges inside one text box

A `Text` clip held one string with one colour, weight and slant. Figma-style mixed styles in one
box needed a range model.

- `props.runs` on `Text` (optional, so old docs parse unchanged): code-point ranges with their own
  `color`, `weight`, `italic`. `src/lib/motion/text-runs.ts` owns normalising, styling a range
  (bold/italic toggle like Figma), keeping runs on their characters while typing (`shiftRuns`,
  prefix/suffix diff) and splitting text into segments.
- GPU: `layout.ts` asks the font book per character (`requestAt`), `painter.ts` splits ink units
  by run colour. Runs force the TS outline path instead of the native Rust layout, which has no
  run model; the native plan is stripped of the run fields (`UniformPlan`).
- HTML export: `templates.ts` wraps runs in spans. Text with animators keeps plain rendering.
- Canvas: in the text editor ⌘B / ⌘I toggle the selection, a small bar over the box adds colour
  and clear. MCP: `style_text_range` (frame family of `edit`).

Discarded for now: per-run size, family and tracking (they change line metrics and the native
layout); live rich preview inside the textarea (caret misaligns with mixed weights).
