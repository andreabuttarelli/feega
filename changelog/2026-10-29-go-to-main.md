# Go to main component

An instance had no way back to its main. Now the Instance inspector header, the element
right-click menu (`go-to-main`) and each Components panel row ("Show main") lead to it: same
canvas pans and selects; another canvas navigates with `?frame=&main=`, handled in
`afterNavigate` because the canvas page is reused across canvases and `onMount` never re-ran.

- A carried main remembers its frame: `mainComponentSchema.home`, set by `homed()` whenever a
  component is placed from another frame (drop, paste, free drop). A main with no `home` lives in
  the frame that holds it. Instances carried before this change have no `home` and resolve to
  their own frame.
- `mainLocation` names `canvas › frame` for the tooltip; the project components listing now
  carries `frameName` and `home`.

Not fixed, listed: an instance in another frame holds a copy of the main (`placeInstance`
copies the comp). Edits on the main reach instances in the same frame only; instances in other
frames or canvases do not receive them. This predates this change.
