# Phone split template

Built-in `builtin:phone-split`: a pro smartphone rises from below (pure in-out expo, optional
tilt settling upright), then the headline halves enter hugging its edges, reusing split
headline's split/axis rules (now in `template/split-line.ts`, moved in a separate commit).
Loop: words leave, phone descends; last frame equals the first.

Device is CSS 3D, not three.js: seen head-on the titanium is only a rim, the screen must stay
crisp DOM, and CSS costs nothing on the farm's software GL. No maker name or logo; a test holds it.
Empty media shows a recreated app screen; otherwise image or video.
