# Inpaint (F1, 4)

`image_tool` gains `inpaint` {prompt, mask}. Mask = brush strokes/regions as fractions of the
image (`lib/image-mask.ts`); the server draws it to a black/white PNG at the source's pixel size
(`server/image-mask.ts`), stores it as an asset (`edit-assets.ts`) and keeps it on the new node
as `maskRefId`. `generate.ts` signs it and sends it through `maskUrl` -> `wire.fields.mask`;
models with `requiresMask` refuse before spending without one. Model: kie `ideogram/v3-edit`,
priced per rendering speed (6/12/18 credits: estimates, verify). UI: `InpaintDialog` (brush
canvas over the picture + prompt) -> page action `imageTool` with `mask` JSON.
Not verified: ideogram's mask polarity (white = repaint assumed).
