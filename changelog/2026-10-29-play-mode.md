# Play mode: prototype arrows, node lines hidden

Issue #1516, spec `docs/specs/editor-modes.md`.

Before: Play rendered a placeholder panel; prototype arrows were drawn in every mode from the frame's right edge, on top of node-to-node lines.

Now: `MODES` gains `lines` (`CanvasLines.Nodes | Prototype`). In Play, `GpuFlow` drops node curves (render and edge hit) and draws `PrototypeArrows`; elsewhere the reverse. Arrows start at the linked layer's outline (`elementKey`, `elementEdge`). A handle on the single picked layer drags to a frame: `prototypeLink.aim` then `linkPrototype` on pointerup, the same `linkToFrame` the Link to frame button uses. Clicking an arrow enters the source frame with that layer picked, so the existing `PrototypeSection` edits it — no second data model. `ModeInspector.Soon` became `Play`: `PlayInspector` hosts PrototypeSection, FlowSection (Play, Copy play link), a Play on canvas switch (`frameLive`) and InteractivePanel. The player's start falls back to the one selected frame when not inside one.

Kept: the Interactive dialog in "…" and the frame overlay Play switch. Not done: fullscreen player on mobile beyond what PrototypePlayer already does.
