# More section names from headings

`SECTION_NAMES` gains Customers, Integrations, How it works, Use cases, Security, Team, AI, and
"blog" joins News. Customers left Testimonials: a "customers" section is usually logos or case
studies, not quotes. AI matches only the heading (`ai`, `agent`), Team only "meet the team" /
"our team" / a heading starting with "Team": "for modern teams" is copy, not a section.
Unmatched sections stay `Section N`; no AI.
