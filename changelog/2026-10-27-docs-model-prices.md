# Docs list the price of every model

New generated page `reference/generated/model-prices`: one filterable, sortable table of every model with provider, kind, unit and credits per unit, at the real charge (provider dollars x 1.2 x 100 = 120 credits per dollar, `credit-ladder.ts`). Prices are not in the code for most providers: they live in `ai_models` (OpenRouter, Wiro, Kie) and in Kie's public price list. `web-docs/scripts/refresh-model-prices.mjs` reads them (SELECT only) into the committed `web-docs/data/model-prices.snapshot.json`; the build renders that snapshot plus ElevenLabs, Kie text and Higgsfield from code, so the page states the snapshot date. Higgsfield quotes per request and Wiro `cp-readoutput` models are metered, so they show "not published" rather than a guess. Rejected: a hand-written table (drifts) and a build-time database read (the docs build has no credentials).
