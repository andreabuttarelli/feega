# Bottom bar mode switch is a pill

The Design/Motion/Play/Code control used `rounded-md` inside a full-pill
bar. `SegmentedControl` takes `shape` (`SegmentedShape.Pill`), used only
by `CanvasAddBar`: track, thumb and items are `rounded-full`, with the
track's 2px padding as the inset, so inner radius = bar radius - inset.
Other usages keep the default radii.
