# Shots v4: vertical type, word limits, app screens, export smoothness

Fixes the defects of the v3 trailer test (`~/Documents/feega-videos/feega-trailer-test/v3/`).

**Type scale by aspect.** `titleSize` sized every title by the frame width, so in 9:16 titles
were ~0.14 of the width. The prelude now has `fitRows`: it tries every wrap width, at most 2 rows
in landscape and 4 in vertical, and keeps the largest size that fits both the height share and
the width. Kinetic title, tagline, before-after and stat use it; captions use `CAPTION`, larger in
vertical. Test: every title shot is at least 0.18 of the width in 9:16 and no word leaves the
frame. `drawPiece` takes a frame size so shots are tested at 1080×1920.

**Slot limits.** `ShotSpec.limits` declares words and characters per text slot (a title 6 words,
a tagline 6 words / 40 chars). `addShot` refuses a longer text and offers a cut; `list_shots`
returns `text_limits`. The limits table replaced the `TEXT_SLOTS` list that `shotWords` read, so
the text slots are listed once.

**App screens.** `recreate_ui` with a url opened the page signed out, so a SaaS trailer showed the
marketing site. `vectorCapture` now takes a `SignedIn` port: `savedSession` hands it the session
`app_browse` saved for the project when the url is on the same app. A page that bounces to the
sign-in is refused with "sign in with app_browse". Prompt and launch-film style tell the agent to
ask for a test account and rebuild the logged-in screens. In dev `requestVerdict` lets the browser
open `PUBLIC_APP_URL`'s origin, so app_browse can sign in to the local app; every other private
address stays closed and production is unchanged (`NODE_ENV`).

**Vertical layouts.** Before-after stacks in 9:16 (the UI wipes in from the bottom under the pain
line). Ui-focus dimmed the page to 6% until the result; it now dims to 45% while typing only.

**Smoothness on export.** `encodeMp4` takes a `JoltMeter`: each encoded frame is drawn at 192 px,
turned to luma and diffed against the last; `renderInBrowser` reports `motionJolts` outside the
doc's cuts (`docCuts`, shared with `scripts/motion-smoothness.ts`), and the export dialog says at
which seconds. Discarded: running it in the sampled gate (too few frames to see a one-frame pop).

**Eval metric.** `uiLayers` in `eval:motion` counted every non-kit Custom clip as recreated UI;
now only components that embed the vector UI count.
