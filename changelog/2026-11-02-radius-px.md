# Inspector radius takes px, Stack child rows are chips

The Appearance radius chip and slider edited `roundness` (0 to 0.5 of the short side), so
typing 12 clamped to 0.50. They now show and accept px, converted with the short side of the
element's shown box (the laid box for a Stack child): slider max is half of it. The
per-corner inputs use the same px. Stored value is unchanged.

`src/lib/motion/radius-px.ts` holds the conversion; `radius-px.test.ts` fails on the old
behaviour (12 typed must render a 12px radius).

Stack child rows (Align self, In layout, grid span and In cell) move from label-left form
rows to the chip style of the rest of the Stack section. Test ids are unchanged.
