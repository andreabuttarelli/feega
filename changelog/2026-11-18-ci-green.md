# CI `test` green again on dev

Three unit tests failed on dev, none from the change that exposed them.

- `cli/cli-parses.test.ts` runs `bun cli.ts --help`. The test job installed only the root
  dependencies, so `commander` resolved to the root's 7.2.0, which has no `hook`. The job now
  installs `cli/` with `bun install --frozen-lockfile`, as `cli-release.yml` does.
- `sheet-pages.test.ts` listed `brand`, `danger`, `products` as canvas settings sections. They
  moved to the dashboard (#2388). The test now takes the sections from `CANVAS_SETTINGS_GROUPS`,
  so a section shown on the canvas without a page fails it, and the next move needs no edit.
