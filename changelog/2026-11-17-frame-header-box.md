# Frame header icons in a box

Header icons (Play, GitHub status, component, breakpoints) were 12px glyphs
on bare header text. Now one rounded box (4px radius, label colour at 14%)
holds them: 20px slots, 2px apart, 3px padding, 13px glyphs. Size is screen
px, constant at every zoom. Hit areas are the slots. Name truncation and the
narrow-frame rule (Play survives longest) count the box width.
