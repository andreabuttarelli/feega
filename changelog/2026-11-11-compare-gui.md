# Comparison page: Feega vs Gui

Gui (usegui.com) edits a running app through the user's own ACP agent; people evaluating
"design from code" tools meet both. Added `tools/gui.ts` with the same feature keys as the
other pages. Gui wins stated plainly: live app editing, bring-your-own agent with no AI cost,
open source, native Mac app. Feega claims checked in code: dev server detection
(`code-import/repo.ts`), component marks for React/Vue/Svelte (`component-marks.ts`),
Storybook (`storybook.ts`), write-back (`write-back.ts`, `repo-sync.ts`), URL import.
Blog index description left unchanged: adding Gui broke its length limit.
