# Graphic style: a poster exercise without a script

A real chat run ("poster svizzero brutalista") kept the `no-script` warning to the end: the doc had
no style, so it fell back to launch film, whose gate wants a `write_script` with sources from a
brand site — impossible for a look exercise with no product.

- `StyleSpec.script` (`Script.Required | Script.Free`) in the one `STYLES` table; `unscripted`
  reads it instead of `SCORED`. Only launch film requires it now; UI morph no longer does (a reel
  of interface states has no four-act story).
- New style `graphic` (Graphic poster): huge edge-bleeding type, visible grid, small text columns,
  condensed grotesks from Google Fonts, references lead composition and type scale. No title-card,
  title-type or too-much-text gates; music not demanded.
- Prompt: `set_style` names `graphic` for a poster, type or look exercise.
- Discarded: dropping the requirement when `doc.style` is unset — real launch films rarely set it.
