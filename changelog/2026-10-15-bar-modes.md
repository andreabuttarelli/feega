# Canvas bar: Design and Generate sets

With draw tools always on, the canvas bar held draw tools, upload, three generation buttons, more,
templates and frame templates — too long. `bottom-bar.ts` now keys slots by context and `BarMode`
(one table, `barSlots(context, mode)`):

- Canvas · Design: switch, draw tools (incl. select), upload, frame templates.
- Canvas · Generate: switch, select, all five generation mediums (`CANVAS_BAR_MAIN = GEN_MEDIUMS`,
  ¶+ style icons incl. new audio/3D ones), more, templates, frame templates.
- Frame (open): frame tools only, no switch, whatever the mode (#530 behaviour kept).

Mode in localStorage (`feega:canvas-bar-mode`), default Generate. Draw shortcuts now also work on
the canvas in either set (`tool` canvas command, keys looked up from the editor's `SHORTCUTS`
table, not copied). On phones the switch stacks vertically and buttons shrink to fit 390 px.
Discarded: a single "Generate" button with a menu (one more click for the most common action).
