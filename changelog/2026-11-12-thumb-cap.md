# Frame thumbnails capped like sources

Thumbnails reuse the frame cache LRU (`frameCache<Blob>`): 1500 entries /
128 MB per user+org, one revision per frame, keys prefixed by canvas. The
old single `thumbs` store is dropped on upgrade (shelf v2).

`tests/e2e/frame-cache-fresh.spec.ts`: client B writes a new head while A
is away; A reopens and must match B's render, never its cached one.
Verified it fails when the cache key ignores the revision.

Reopen, heavy copy, local dev on prod DB (4 runs): frame sources wait
3.4–5.3 s / 102 KB cold vs 0.32–0.34 s / ≤6 KB warm.
