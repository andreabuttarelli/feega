# Import from code: edits go back to the code, and the code comes back to the canvas

Spec `docs/specs/code-import.md`, section "Sync with the source".

- Every imported layer that comes from an element of the repo carries `source` (`at` = `file:line:col`, `was` = the look the import drew). Read in the page from Svelte 5 `__svelte_meta.loc` and React ≤18 `_debugSource`; `page-tree` stamps it, `rest-message`/`scene`/`figma-doc` carry it to the clip (`motion-core` clip schema). `was` is taken after `urlPlan` (`baselined` in `code-doc`): `coloursMerged` and the component pass retouch colours and texts, and a baseline taken at layer build turned those into fake edits.
- One registry, `LOOK` (`src/lib/canvas/code-look.ts`): text, colour, fill, font size, gap, padding, direction — how each is read from a clip, written onto it, and turned into CSS. A new property is a row.
- Write-back (`write-back.ts`): a changed look becomes an edit at its element; style lands as inline `style` (merged with an existing `style="…"`, `style={{…}}` for JSX); text is replaced when the element holds it literally, else in the inlang catalogue (`project.inlang/settings.json`), by the `m.key()` the element calls or by a unique value. Anything else is reported, not guessed. Output: files + unified patch.
- Port `CodeSource` (`code-source.ts`) with two adapters: GitHub (`repo-sync.ts`: raw/contents reads, `openPullRequest` = new `feega/…` branch + contents PUT + PR, refused when the branch is the default one) and local folder (`folder-source.ts`: reads/writes the files, commits them on a `feega/…` branch with git plumbing and a temporary index so the working tree and the user's branch stay as they are; head = hash of sizes and mtimes). The use case (`code-sync.ts`) picks the adapter from a table on `nodes.data.code.kind`.
- Pull: re-import at the new head into a scratch frame, `rebased` carries each local edit onto the matching element (same file and same original look, else same location); where the code changed that property too, the code wins and the conflict is listed. The merged doc is written on the original node, the scratch frame removed.
- Folder import (local mode only, `localModeRefusal`): the folder's own dev server runs on a free loopback port (kept per folder), captured with the local Chromium; `localBrowser` takes the one origin it may reach. No sandbox, no rate limit.
- GitHub calls: the Composio connection when there is one, else `GITHUB_TOKEN` (self-host/local). `ProviderCall` gained `method`/`body`.
- `instance-diff` ignores `source`: every usage has its own `was`, and comparing it unlinked 13 of 14 instances on traidue.
- UI: code mode shows the sync panel (patch, Patch download, Open pull request / Write to folder, Pull with branch); for a folder it polls the head every 3 s and pulls on change. API `…/code-import/:nodeId/{changes,publish,pull,head}`, ops `code_changes|code_publish|code_pull`, CLI `feega canvas code-sync`.
- Discarded: a DOM-path or geometry match between canvas and source (breaks on the first re-layout); diffing against revision 1 (local mode keeps only heads); Tailwind class rewriting (inline style is exact and framework-agnostic; classes can come later as a `LOOK` column).
