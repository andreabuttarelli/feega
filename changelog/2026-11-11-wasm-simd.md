# Perf: build the engine wasm with SIMD

`packages/gpu-core/.cargo/config.toml` sets `+simd128` for `wasm32-unknown-unknown`. Every
browser with WebGPU runs wasm SIMD, so there is no fallback build. `fearless_simd` picks
`WasmSimd128` at compile time when the feature is on (`Level::new`), so vello_common /
vello_hybrid strip rendering and the scalar loops LLVM can vectorise take the SIMD path: the
module goes from 0 to ~7 600 v128 instructions.

Size on top of the glyphless build: 2 071 081 → 1 970 141 bytes raw (gzip 619 k → 601 k, brotli
450 k → 438 k).
