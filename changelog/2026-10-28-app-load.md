# /app loads faster

`/api/v1/me/pages/home` recomputed the dashboard that `/api/v1/me/bootstrap` already
returns. Home now returns only templates, tools and attach target; `/app/+page.ts` takes
`dashboard` from the bootstrap load (same SWR cache entry, no extra request). Home: ~240ms →
~70ms locally; `/app` waits on bootstrap alone (~180ms).

The root layout no longer awaits the asset grant; failures are logged.
