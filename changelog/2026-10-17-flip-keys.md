# Flip ⇧H / ⇧V and in the right-click menu

Figma flips with ⇧H / ⇧V (help.figma.com 360039956914). Flip existed only as two inspector
buttons for one layer. `flipClips` (`motion/layer-props.ts`) negates the scale on the axis of
every selected layer; an animated scale is negated on every keyframe so the motion stays
mirrored. Commands `FlipHorizontal`/`FlipVertical` run it from the keys and from the frame
right-click menu (`flip-horizontal`/`flip-vertical` rows in the shared table).

Decision: a multi-selection flips each layer in place, not mirrored as one block around the
selection centre (Figma's exact multi-layer behaviour is not stated in the help page).
Canvas tiles do not flip: a tile has no scale model. Parity: `set_transform` with scaleX/scaleY.
