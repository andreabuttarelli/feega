# Introducing badge template

Built-in `builtin:introducing-badge`: "Introducing [glass pill badge] Product" on a near-black
field with green corner glow and a large planet arc rising from the bottom. Words use the shared
word entrance; the badge grows 0.9 → 1 with expo in-out (no overshoot) and gets one shine sweep
after landing. Row in landscape, column below 1.25 aspect. Loops: all leaves in the last ~1.4 s.

Badge is a full pill, not the reference's rounded rectangle (shape rule). Default glyph is a CSS
"N"; an optional `logo` media field replaces it. Fictional brand "NOVA kit".
