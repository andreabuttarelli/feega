# Budget bench: a 120 fps level

Target is now 120 fps on high-refresh displays. `perf:budget` judges the same frames against
8.3 ms too (`budgetOf(gaps, Rate.ProMotion)`, reported as `at120`); 90 fps stays the gate.

Baseline at 120 (dev, 3 runs, load 15–88), % frames over 8.3 ms / p95 ms:
heavy pan 0.1–1.0 / 1.9–2.8, zoom 0.7–1.5 / 2.1–3.7, fit 1.2–2.1 / 1.3–2.7, drag 2.1–2.2 / 1.3–2.0;
landings pan 0.2–0.7 / 1.4–1.5, zoom 1.1–1.4 / 3.0–3.5, fit 3.5–4.8 / 2.4–5.1, drag 2.4–2.7 / 2.1–2.3.
