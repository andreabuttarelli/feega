# Dev mode: read a layer as code

Figma has Dev mode; the canvas had measures (Alt-hover) and a properties
panel, but no way to read a layer as code or hand it to a developer without
editing it.

`Shift+D` (View menu, or the Dev mode button on the properties panel) swaps the
editable properties for a read-only inspector:

- `src/lib/canvas/dev-css.ts` turns a clip into declarations (box in px of the
  frame, fill, radius, opacity, rotation, type) through a painter table keyed
  by component, then into CSS text or Tailwind arbitrary-value classes through
  a rule table keyed by property. A new component or property is a row.
- Brand colours stay named: `brand.accent` is listed as a variable and, with no
  brand to resolve it, written as `var(--brand-accent)`. Fonts, named styles
  and bound variables are listed too.
- Hover measures reuse `measuredGaps`; dev mode only lifts the Alt requirement.
- Export reuses the element export dialog (`onExportElements`), handed to the
  panel through `frameProperties.exportPicks`.
- Agent: `read_layer_css` (motion tool, read-only) returns the same CSS,
  Tailwind, box and variables. `Command.ToggleDevMode` points at it in the
  parity table.

Discarded: a separate right-bar tab (the panel already switches by selection),
resolving brand values in the tool (the video does not carry the brand, the
render does), SVG/PDF export settings per layer (ticket T5).
