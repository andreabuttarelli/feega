# A blog at blog.feega.app

Build-in-public posts had no home outside LinkedIn. `web-blog/` is a static
Astro site (MDX collection, tags, RSS, sitemap, OG covers, `BlogPosting`
JSON-LD), deployed like web-docs: a `web-blog` entry in the deploy matrix
(Vercel project `prj_BoTkXM9Cx4NCXcjVGfOJMIx5W8iz`) and a CI build job.

- Standalone app, no root install: it reads nothing from the main app.
- One narrow column, BDO Grotesk, near-monochrome, orange only on hover.
- Demo videos are loaded from docs.feega.app instead of duplicating mp4s.
- Covers are generated once with `npm run covers` (sharp) and committed.
- Discarded Starlight: a docs theme, not a reading layout.
